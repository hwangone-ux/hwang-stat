# Stat-Helper

설치 없이 브라우저에서 바로 쓰는 통계 분석 연습 도구입니다. 파일 하나(`index.html`)에 모든 기능과 예제 자료가 들어 있습니다.

- 사용 주소: https://hwangone-ux.github.io/hwang-stat/
- 비상업적 배포 연습용입니다.

## 기능

- **분석**: 기술통계, 상관, 독립·종속 t-검정, 일원·이원분산분석, 공분산분석, 비모수검정 4종, 교차분석, 선형·단계적·위계적 회귀(잔차 진단 포함), 신뢰도분석
- **테이블**: 단순빈도표, 이원빈도표, 단순평균표, 이원평균표
- **그래프**: 막대, 선형, 파이, 분포도, 산점도, 상자도, 워드클라우드, 네트워크 분석
- **파일**: `.istat`·CSV·Excel 열기, `.istat` 저장, 예제 다운로드(`.istat`·`.csv`·`.xlsx`)

## 로컬에서 쓰기

`index.html`을 내려받아 더블클릭하면 됩니다. Excel 파일 열기만 인터넷 연결이 필요합니다.
